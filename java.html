☕ Java

Conceitos essenciais da linguagem Java.

1. O que é Java e como funciona?

Java é uma linguagem de programação orientada a objetos, utilizada para criar aplicações, sistemas backend e APIs.

O código-fonte é compilado para bytecode, que é executado pela JVM(Java Virtual Machine).

  • JDK: ferramentas para desenvolver e compilar programas JAVA.
  • JRE: ambiente necessário para executar aplocações JAVA.
  • JVM: executa o bytecode.

2. Variáveis e tipos de dados

Variáveis armazenam valores. O tipo define qual categoria de dado será armazenada. 

String nome = "Amanda";
int idade = 44;
double salario = 2500.00;
boolean ativo = true;
char letra = 'A';

    Tipos Primitivos

  • String: textos.
  • int: números inteiros.
  • double: números decimais.
  • boolean: verdadeiro ou falso.
  • char: um caractere.
  • byte: números inteiros pequenos, de -128 a 127.
  • short: números inteiros de -32.768 a 32.767.
  • long: números inteiros longos.
  • float: números decimais com menor precisão que double.

    Tipos de Referência e Conversões

  • Referência: váriaveis que apontam para objetos, como String, arrays e instâncias.
  • Conversão automática (widening): por exemplo, int para long.
  • Conversão explícita (narrowing): pode perder informações, por exemplo int n = (int) 8.7; resulta em 8.
  • Wrapper classes: Integer, Double, Boolean, etc. São os primitivos como objetos.
  • Autoboxing/unboxing: conversão automática entre primitivo e wrapper, por exemplo, int <--> Integer.

3. Operadores

int soma = 10 + 5;
int subtracao = 10 - 5;
int multiplicacao = 10 * 5;
int divisao = 10 / 5;
int resto = 10 % 3;
  • +: adição.
  • -: subtração.
  • *: multiplicação.
  • /: divisão.
  • %: resto da divisão.
  • ==: compara igualdade.
  • !=: compara diferença.
  • &&: E lógico.
  • ||: OU lógico.

4. Condicionais e laços

O if e o else executam códigos conforme uma condição.

int idade = 18;
if (idade >= 18) {
   System.out.println("Maior de idade");
} else {
   System.out.println("Menor de idade");
}

O for e o while permitem repetir instruções.

for (int i = 1; i <= 3; i++) {
   System.out.println(i);
}

5. Métodos

Métodos agrupam instruções para realizar uma tarefa. Podem receber parâmetros e retornar valores. 

public int somar(int a, int b) {
   return a + b;
}

return: devolve o resultado.

void: indica que o método não retorna um valor.

6. Orientação a objetos (POO)

  • Classe: modelo para criar objetos.
  • Objeto: instância de uma classe.
  • Encapsulamento: protege e controla o acesso aos dados.
  • Herança: permite que uma classe herde características de outra.
  • Polimorfismo: permite diferentes comportamentos por meio de uma mesma interface ou classe base.
  • Abstração: destaca o essencial e esconde detalhes de implementação. 
public class Pessoa {
   private String nome;
   public String getNome() {
       return nome;
   }
   public void setNome(String nome) {
       this.nome = nome;
   }
}

7. Modificadores de acesso

  • public: acessível de qualquer pacote, respeitadas as regras de visibilidade do tipo.
  • private: acessível dentro da própria classe.
  • protected: acessível no mesmo pacote e também em subclasses, conforme as regras de acesso.
  • static: pertence à classe, não a cada objeto.
  • final: impede alterações conforme o contexto: variável, método ou classe.

8. Comparable, Comparator, equals e hasCode

  • Comparable: define a ordem natural dentro da própria classe, pelo método compareTo().
  • Comparator: cria uma regra de comparação externa, pelo método compare(), pode usar Lambda.
  • Equals: verifica igualdade lógica, equals().
  • HasCode: gera um número usado por estruturas hash para localizar objetos, hasCode().
  • Importante: se dois objetos são iguais por equals(), precisam ter o mesmo hasCode(). O inverso não é obrigatório. Se uma classe for usada em HasSet/HasMap, implemente corretamente os dois métodos, considerando os campos que definem igualdade.

9. Collections — List, Set e Map

Collections são estruturas usadas para armazenar e manipular grupos de elementos.

List — Lista ordenada

Permite elementos duplicados e mantém a ordem de inserção. O ArrayList permite acessar elementos por índice. 

List<String> nomes = new ArrayList<>();
nomes.add("Amanda");
nomes.add("Pedro");
nomes.add("Amanda");
System.out.println(nomes);
// [Amanda, Pedro, Amanda]

ArrayList

Permite elementos duplicados e implementação de List baseada em array dinâmico. É adequada para acessos frequentes por índice.

LinkedList

Permite elementos duplicados e implementação de List baseada em lista duplamente encadeada. Mantém a ordem e permite duplicados.

Set — Conjunto sem duplicados

Não permite elementos duplicados segundo as regras de igualdade de objetos.

HashSet

Não permite duplicados, e não garante uma ordem específica de iteração. 

Set<String> linguagens = new HashSet<>();
linguagens.add("Java");
linguagens.add("Python");
linguagens.add("Java");
// Java aparece apenas uma vez.
// A ordem de exibição não é garantida.

LinkedHashSet

Não permite duplicados e mantém a ordem de inserção. 

Set<String> nomes = new LinkedHashSet<>();
nomes.add("Amanda");
nomes.add("Pedro");
nomes.add("Valentina");
// [Amanda, Pedro, Valentina]

TreeSet

Não permite duplicados e organiza os elementos em ordem natural ou conforme um Comparator. 

Set<String> frutas = new TreeSet<>();
frutas.add("Uva");
frutas.add("Abacaxi");
frutas.add("Banana");
// [Abacaxi, Banana, Uva]

Map — Chave e valor

Armazena pares de chave e valor. As chaves são únicas; valores podem se repetir. Map não faz parte da hierarquia Collection.

HashMap

Armazena pares de chave(key), não aceita chaves duplicadas, mas aceita valores(value) duplicados, sem garantir uma ordem específica de iteração. 

Map<String, Integer> notas = new HashMap<>();
notas.put("Amanda", 10);
notas.put("Pedro", 8);
notas.put("Valentina", 9);
// A ordem de iteração não é garantida.

LinkedHashMap

Mantém, por padrão, a ordem de inserção das entradas. 

Map<String, Integer> notas =
   new LinkedHashMap<>();
notas.put("Amanda", 10);
notas.put("Pedro", 8);
notas.put("Valentina", 9);
// Iteração na ordem de inserção.

TreeMap

Organiza as entradas pela ordem natural das chaves ou por um Comparator. 

Map<String, Integer> notas = new TreeMap<>();
notas.put("Pedro", 8);
notas.put("Amanda", 10);
notas.put("Valentina", 9);
// Chaves: Amanda, Pedro, Valentina.

Resumo para memorizar

  • ArrayList: mantém a ordem, aceita duplicados.
  • LinkedList: mantém a ordem, aceita duplicados.
  • HashSet: sem duplicados, sem ordem garantida.
  • LinkedHashSet: sem duplicados, ordem de inserção.
  • TreeSet: sem duplicados, elementos ordenados.
  • HashMap: chave e valor, sem ordem garantida.
  • LinkedHashMap: mantém a ordem de inserção.
  • TreeMap: ordena pelas chaves.

10. Generics, Type Safety e Wildcards

Generics: permitem definir o tipo que uma classe ou coleção aceita, aumentando a segurança e reduzindo casts. 
List {
   int resultado = 10 / 0;
} catch (ArithmeticException e) {
   System.out.println("Erro matemático");
} finally {
   System.out.println("Finalizado");
}
  • .
  • catch: trata uma exceção compatível.
  • finally: bloco executado após try/catch, salvo situações excepcionais.
  • throw: lança uma exceção.
  • throws: declara exceções que um método pode propagar.

11. Tratamento de exceções

Exceções representam situações que afetam o fluxo normal do programa. 

try {
   int resultado = 10 / 0;
} catch (ArithmeticException e) {
   System.out.println("Erro matemático");
} finally {
   System.out.println("Finalizado");
}
  • try: contém o código que pode gerar uma exceção.
  • catch: trata uma exceção compatível.
  • finally: bloco executado após try/catch, salvo situações excepcionais.
  • throw: lança uma exceção.
  • throws: declara exceções que um método pode propagar.
