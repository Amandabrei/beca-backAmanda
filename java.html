☕ Java

Conceitos essenciais da linguagem Java.

01. O que é e como funciona?

Variáveis e tipos primitivos

Java é uma linguagem de programação orientada a objetos, utilizada para criar aplicações, sistemas backend e APIs.

O código-fonte é compilado para bytecode, que é executado pela JVM(Java Virtual Machine).

  • JDK: ferramentas para desenvolver e compilar programas Java.
  • JRE: ambiente necessário para executar aplicações Java.
  • JVM: executa o bytecode.

02. Fundamentos da linguagem

Variáveis armazenam dados. Java possui oito tipos primitivos:

  • byte, short, int e long: números inteiros.
  • float e double: números decimais.
  • char: um caractere.
  • boolean: verdadeiro ou falso.
int idade = 40;
double altura = 1.55;
char letra = 'A';
boolean aprovado = true;

Entrada, processamento e saída de dados

Um programa recebe dados, realiza operações e apresenta o resultado.

Scanner sc = new Scanner(System.in);

System.out.print("Digite seu nome: ");
String nome = sc.nextLine();

System.out.println("Olá, " + nome);

Operadores aritméticos

Realizam cálculos matemáticos:

int soma = 10 + 5;
int subtracao = 10 - 5;
int multiplicacao = 10 * 5;
int divisao = 10 / 5;
int resto = 10 % 3;

O operador % retorna o resto da divisão. A divisão entre inteiros também retorna um inteiro.

Atribuição acumulativa

Atualiza o valor de uma variável usando o próprio valor.

int total = 10;
total += 5; // total = 15
total -= 2; // total = 13
total *= 2; // total = 26

Expressões comparativas e lógicas

Comparações retornam boolean. Operadores lógicos combinam condições.

int idade = 20;

boolean maior = idade >= 18;
boolean valido = idade >= 18 && idade < 60;
boolean fora = idade < 18 || idade > 60;
boolean negado = !maior;

Funções matemáticas

A classe Math disponibiliza métodos matemáticos.

Math.sqrt(25); // raiz quadrada: 5
Math.pow(2, 3); // potência: 8
Math.abs(-10); // valor absoluto: 10
Math.round(4.6); // arredonda: 5
Math.max(5, 9); // maior valor: 9

Operadores bitwise

Manipulam os bits de números inteiros.

int a = 5; // 0101
int b = 3; // 0011

int and = a & b; // 0001 = 1
int or = a | b; // 0111 = 7
int xor = a ^ b; // 0110 = 6
int shift = a << 1; // 1010 = 10

Strings

String representa textos. É possível consultar e transformar seu conteúdo.

String texto = "Java"

texto.length(); // tamanho
texto.toUpperCase(); // JAVA
texto.toLowerCase(); // java
texto.substring(0, 2); // Ja
texto.contains("av"); // true
texto.equals("Java"); // true

Atenção: Strings são imutáveis. Métodos como toUpperCase() retornam uma nova String.

03. Estruturas de controle

Condicional if e else

Executa um bloco conforme uma condição.

int idade = 20;

if (idade >= 18) {
    System.out.println("Maior de idade");
} else {
    System.out.println("Menor de idade");
}

Switch case

Seleciona uma alternativa entre vários casos.

int dia = 2;

switch (dia) {
    case 1:
        System.out.println("Domingo");
    break;
    case 2:
        System.out.println("Segunda");
    break;
    default:
        System.out.println("Outro dia");
}

Operador ternário

Uma forma compacta de escolher entre dois valores com base em uma condição.

int idade = 20;

String resultado =
idade >= 18 ? "Maior" : "Menor"

Sintaxe: condição ? valorSeVerdadeiro : valorSeFalso.

Estruturas repetitivas

Executam um bloco de código repetidamente.

// for: quando conhecemos a repetição
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// while: verifica antes de executar
int i = 0;
while (i < 5) {
    i++;
}

// do-while: executa pelo menos uma vez
do {
    i--;
} while (i > 0);

Escopo e inicialização

Escopo é a região em que uma variável pode ser acessada. Variáveis locais precisam ser inicializadas antes do uso.

int numero = 10;

if (numero > 0) {
    int resultado = numero * 2;
}
// resultado não existe fora do bloco

Convenções e restrições

  • Classes: PascalCase, por exemplo Cliente.
  • Variáveis e métodos: camelCase, por exemplo calcularTotal().
  • Constantes: geralmente MAIUSCULAS_COM_UNDERSCORE.
  • Java diferencia letras maiúsculas e minúsculas.
  • Palavras reservadas não podem ser usadas como identificadores.

04. Programação Orientada a Objetos (POO)

Classes, objetos e instanciação

Classe é um modelo.

Objeto é uma instância criada a partir desse modelo.

public class Cliente {
    String nome;
    int idade;

    void apresentar() {
        System.out.println(nome);
    }
}

// Criando um objeto:
Cliente cliente = new Cliente();
cliente.nome = "Amanda"
cliente.apresentar();

Atributos, métodos e membros estáticos

Atributos representam características.

Métodos representam comportamentos.

Membros static pertencem à classe, e não a cada objeto.

public class Contador {
    static int total = 0;

    Contador() {
        total++;
    }
}

Construtores e sobrecarga

Construtores inicializam objetos.

Sobrecarga permite ter métodos ou construtores com o mesmo nome, mas parâmetros diferentes.

public class Produto {
    String nome;
    double preco;

    Produto(String nome) {
        this.nome = nome;
    }

    Produto(String nome, double preco) {
        this.nome = nome;
        this.preco = preco;
    }
}

Modificadores de acesso

  • private: acessível dentro da própria classe.
  • public: acessível de qualquer lugar permitido.
  • protected: acessível no pacote e por subclasses.
  • Sem modificador: acesso de pacote.

Tipos primitivos e tipos de referência

Primitivos armazenam valores como números e booleanos.

Variáveis de referência apontam para objetos.

int numero = 10;
Cliente pessoa = new Cliente();

Cliente outra = pessoa; // referência ao mesmo objeto

Variáveis de referência podem receber null, que significa ausência de referência a um objeto.

Valores padrão e Wrapper

Atributos recebem valores padrão, como 0, false ou null. Variáveis locais não recebem valores padrão automaticamente.

Classes Wrapper representam tipos primitivos como objetos: Integer, Double, Boolean e outras.

int numero = 10;

Integer objeto = numero; // boxing
int valor = objeto; // unboxing

Garbage Collector

O Garbage Collector (GC) recupera memória ocupada por objetos que não são mais alcançáveis. Sair do escopo de uma variável não significa que o objeto será imediatamente desalocado.

Herança e polimorfismo

Herança permite que uma classe reutilize características de outra.

Polimorfismo permite tratar objetos diferentes por um tipo comum.

class Animal {
    void emitirSom() {
        System.out.println("Som");
    }
}

class Cachorro extends Animal {
    @Override
    void emitirSom() {
        System.out.println("Au au");
    }
}

Animal animal = new Cachorro();
animal.emitirSom(); // Au au

Upcasting e downcasting

Upcasting trata um objeto de uma subclasse como o tipo da superclasse.

Downcasting converte a referência de volta para um tipo mais específico e exige cuidado.

Animal animal = new Cachorro(); // upcasting

if (animal instanceof Cachorro) {
    Cachorro cachorro = (Cachorro) animal;
}

final e classes abstratas

  • final em variável: impede reatribuição.
  • final em método: impede sobreposição.
  • final em classe: impede herança.
  • Classe abstrata não pode ser instanciada diretamente.
  • Método abstrato declara um comportamento que a subclasse deve implementar.

Interfaces, IoC e injeção de dependência

Interface define um contrato.

Inversão de Controle (IoC) transfere a responsabilidade de controlar dependências para outro componente ou framework.

Injeção de Dependência (DI) fornece a uma classe os objetos de que ela precisa.

interface Notificador {
    void enviar(String mensagem);
}

class EmailNotificador implements Notificador {
    public void enviar(String mensagem) {
        System.out.println(mensagem);
    }
}

class Servico {
    private final Notificador notificador;

    Servico(Notificador notificador) {
        this.notificador = notificador;
    }
}

Interfaces também podem possuir métodos default, que oferecem uma implementação padrão.

UML e categorias de classes

UML representa visualmente classes, atributos, métodos e relacionamentos.

Classes podem ser organizadas por responsabilidade, como entidades, serviços, controladores e classes utilitárias.

05. Arrays, listas e datas

Vetores e matrizes

Arrays armazenam uma quantidade fixa de elementos do mesmo tipo. O índice começa em zero.

int[] numeros = {10, 20, 30};

System.out.println(numeros[0]); // 10

int[][] matriz = {
    {1, 2},
    {3, 4}
};

System.out.println(matriz[1][0]); // 3

Enumerações

enum define um conjunto fixo de constantes.

enum Status {
    PENDENTE,
    APROVADO,
    CANCELADO
}

Status pedido = Status.APROVADO;

Data e hora — ISO 8601

ISO 8601 é um padrão para representar datas e horários, como 2026-10-17T10:30:00Z.

import java.time.Instant;
import java.time.LocalDate;

Instant agora = Instant.now();
LocalDate hoje = LocalDate.now();

Instant representa um instante na linha do tempo, normalmente em UTC.

LocalDate representa apenas uma data, sem horário.

Calendar

Calendar é uma API antiga de datas. Em código moderno, prefira as classes de java.time, como LocalDate, LocalDateTime e Instant.

06. Exceções e arquivos

Tratamento de exceções

Exceções representam situações que interrompem o fluxo normal do programa.

try {
    int resultado = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Não é possível dividir por zero");
} finally {
    System.out.println("Finalizando");
}

Exceções verificadas (checked) precisam ser tratadas ou declaradas.

Exceções não verificadas (unchecked) incluem subclasses de RuntimeException.

Manipulação de arquivos

A classe File representa caminhos e informações de arquivos. Para leitura e escrita, existem classes como FileWriter, BufferedReader e BufferedWriter.

File arquivo = new File("dados.txt");

try (BufferedWriter writer =
new BufferedWriter(new FileWriter(arquivo))) {
    writer.write("Estudando Java");
}

O BufferedReader permite ler texto de forma eficiente, linha por linha.

O try-with-resources fecha os recursos automaticamente.

07. Generics e Collections Framework

Generics e curingas

Generics permitem definir classes, interfaces e métodos que trabalham com tipos parametrizados, oferecendo segurança de tipos.

List<String> nomes = new ArrayList<>();
nomes.add("Amanda");

// Wildcard: lista de algum tipo de Number
List<? extends Number> valores;

? extends T representa um tipo T ou subtipo. ? super T representa T ou um supertipo.

List, Set e Map

  • List: mantém uma sequência de elementos, permite duplicados e acesso por índice.
  • Set: não permite elementos duplicados segundo a regra de igualdade da coleção.
  • Map: associa chaves a valores; cada chave é única.
List<String> lista = new ArrayList<>();
lista.add("Java");
lista.add("Java");

Set<String> conjunto = new HashSet<>();
conjunto.add("Java");
conjunto.add("Java"); // não adiciona duplicado

Map<Integer, String> mapa = new HashMap<>();
mapa.put(1, "Amanda");
mapa.get(1); // Amanda

Observação: HashSet e HashMap não garantem uma ordem específica de iteração.

equals() e hashCode()

equals() define quando dois objetos são considerados iguais.

hashCode() fornece um código usado por coleções baseadas em hash. Se dois objetos são iguais por equals(), devem ter o mesmo hashCode().

Comparable e Comparator

Comparable define a ordenação natural dentro da própria classe, usando compareTo().

Comparator define uma regra de comparação externa, usando compare().

List<String> nomes = new ArrayList<>();
nomes.add("Valentina");
nomes.add("Pedro");

nomes.sort(Comparator.naturalOrder());

08. Programação Funcional

Expressões lambda e interfaces funcionais

Uma expressão lambda representa uma implementação concisa de uma interface funcional, que possui um único método abstrato.

Runnable tarefa =
() -> System.out.println("Executando");

tarefa.run();

Predicate, Consumer e Function

  • Predicate<T>: recebe um valor e retorna true ou false.
  • Consumer<T>: recebe um valor e executa uma ação, sem retornar resultado.
  • Function<T, R>: recebe um valor T e retorna um resultado R.
Predicate<Integer> par =
n -> n % 2 == 0;

Consumer<String> imprimir =
nome -> System.out.println(nome);

Function<String, Integer> tamanho =
texto -> texto.length();

Stream API e pipeline

Stream permite processar dados de uma coleção em etapas.

Operações intermediárias transformam ou filtram o fluxo.

Operações terminais produzem um resultado ou encerram o processamento.

List<Integer> numeros =
List.of(1, 2, 3, 4, 5, 6);

List<Integer> resultado = numeros.stream()
.filter(n -> n % 2 == 0) // intermediária
.map(n -> n * 10) // intermediária
.toList(); // terminal

Exemplos de operações intermediárias: filter(), map(), sorted() e distinct().

Exemplos de operações terminais: forEach(), collect(), reduce(), count() e toList().

O pipeline é a sequência de operações conectadas que processa os elementos.

09. JDBC — Acesso a banco de dados

O que é JDBC?

JDBC (Java Database Connectivity) é uma API que permite que aplicações Java se conectem a bancos de dados relacionais e executem comandos SQL.

Principais componentes

  • Connection: representa a conexão com o banco.
  • PreparedStatement: executa SQL com parâmetros.
  • ResultSet: permite percorrer os resultados de uma consulta.

Exemplo de consulta

String sql = "SELECT nome FROM cliente WHERE id = ?"

try (Connection conn = DriverManager.getConnection(
    url, usuario, senha);
PreparedStatement stmt = conn.prepareStatement(sql)) {

    stmt.setInt(1, 1);

    try (ResultSet rs = stmt.executeQuery()) {
        while (rs.next()) {
            System.out.println(rs.getString("nome"));
        }
    }
}

O parâmetro ? recebe um valor por meio do PreparedStatement. Isso ajuda a evitar SQL injection e permite reutilizar a consulta parametrizada.

CRUD e padrão DAO

CRUD representa as operações Create, Read, Update e Delete: inserir, consultar, atualizar e excluir dados.

DAO (Data Access Object) separa o código responsável pelo acesso ao banco das regras de negócio da aplicação.

Os comandos SQL e os estudos específicos de PostgreSQL estão na página PostgreSQL deste portfólio.

10. Boas práticas e evolução

  • Utilizar nomes claros para classes, métodos e variáveis.
  • Aplicar encapsulamento e separar responsabilidades.
  • Evitar duplicação de código.
  • Escolher estruturas de dados adequadas para cada problema.
  • Tratar exceções de maneira apropriada.
  • Escrever código legível, organizado e testável.
  • Praticar orientação a objetos e integração com banco de dados.
