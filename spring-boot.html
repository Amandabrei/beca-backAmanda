🌱 Java com Spring Boot

Construindo aplicações e APIs REST.

1. O que é Spring Boot?

É uma ferramenta baseada no Spring que facilita a criação de aplicações Java, reduzindo configurações manuais.

2. Annotations principais

  • @SpringBootApplication: configuração principal da aplicação.
  • @RestController: cria um controlador que normalmente retorna dados.
  • @RequestMapping: define um caminho base para as requisições.
  • @GetMapping: atende requisições GET.
  • @PostMapping: atende requisições POST.
  • @PutMapping: atende requisições PUT.
  • @DeleteMapping: atende requisições DELETE.
  • @Service: identifica uma classe de serviço.
  • @Repository: identifica uma classe de acesso a dados.
  • @Autowired: solicita injeção de dependência; em muitos casos, é preferível usar construtor.

3. Camadas de uma aplicação

  • Entity: representa os dados uma entidade persistida no banco.
  • DTO: transporta dados entre partes da aplicação, sem expor a entidade.
  • Mapper: transforma ema Entity <--> DTO e DTO <--> Entity.
  • Controller: recebe requisições HTTP, como GET, POST, PUT e DELETE.
  • Service: executa a lógica e concentra regras de negócio.
  • Repository: consulta, salva, atualiza e exclui dados no banco.

4. Exemplo de Controller

@RestController
@RequestMapping("/clientes")
public class ClienteController {
   @GetMapping
   public String listar() {
       return "Lista de clientes";
   }
}

Esse exemplo retorna um texto simples. Em uma API real, o Controller normalmente delega a operação para um Service.

5. O que é CRUD?

  • Create: criar registros.
  • Read: consultar registros.
  • Update: atualizar registros.
  • Delete: excluir registros.

Essas operações são frequentemente associadas aos métodos HTTP POST, GET, PUT ou PATCH, e DELETE.

6. JPA e Hibernate

JPA é uma especificação para persistência de objetos Java. Hibernate é uma implementação popular dessa especificação.

@Entity
public class Cliente {
   @Id
   @GeneratedValue(strategy = GenerationType.IDENTITY)
   private Long id;
   private String nome;
}

Uma entidade normalmente representa dados que podem ser armazenados em uma tabela do banco.
