🌱 Java com Spring Boot

Construindo aplicações e APIs REST.

1. O que é Spring Boot?

É uma ferramenta baseada no Spring que facilita a criação de aplicações Java, reduzindo configurações manuais.

2. O que é Maven?

Ferramenta de automação e gerenciamento de projetos Java, com ela você baixa bibliotecas organiza o projeto, compila o código e executa testes, usando diversas dependências e plugins elas são armazenadas no pom.xml do projeto.

3. Annotations principais

  • @SpringBootApplication: configuração principal da aplicação.
  • @RestController: cria um controlador que normalmente retorna dados.
  • @RequestMapping: define um caminho base para as requisições.
  • @GetMapping: atende requisições GET.
  • @PostMapping: atende requisições POST.
  • @PutMapping: atende requisições PUT.
  • @DeleteMapping: atende requisições DELETE.
  • @PathVariable: captura o valor que faz parte da URL, como o ID.
  • @ControllerAdvice: (exceção) centraliza o tratamento de exceções de vários controllers.
  • @Exception Handler: (exceção) define qual método tratará uma exceção específica.
  • ResponseStatus: define o código HTTP que será retornado, como 404 Not Found.
  • @Entity: identifica uma classe como uma entidade.
  • @Service: identifica uma classe de serviço.
  • @Repository: identifica uma classe de acesso a dados.
  • @Autowired: solicita injeção de dependência; em muitos casos, é preferível usar construtor.
  • @Table: nome da tabela no banco de dados.
  • @Id: define a chave primária.
  • @Column: configura a coluna corresnpodente ao atributo.
  • @DataJPATest: (teste) testa camada de persistência, ou seja, verifica se as entidades e repositores funcionam corretamente com o banco de dados.
  • @Bean: indica que o método cria um objeto que será registrado como um Bean.
  • @Configuration: indica que a classe contém configuração do Spring.

4. Camadas de uma aplicação

  • Entity: representa os dados uma entidade persistida no banco.
  • DTO: transporta dados entre partes da aplicação, sem expor a entidade.
  • Mapper: transforma ema Entity <--> DTO e DTO <--> Entity.
  • Controller: recebe requisições HTTP, como GET, POST, PUT e DELETE.
  • Service: executa a lógica e concentra regras de negócio.
  • Repository: consulta, salva, atualiza e exclui dados no banco.

5. Exemplo de Entity

@Entity
@Table(name = "person")
public class Person implements Serializable {

    private static final long serialVersionUID = 1L;

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "name", nullable = false, length = 80)
    private String Name;

    @Column(nullable = false, length = 100)
    private String address;
}

Indica que a classe representa uma entidade no banco de dados.

6. Exemplo de Service

@Service
public class PersonServices {

    private static final org.slf4j.Logger log = LoggerFactory.getLogger(PersonServices.class);
    private Logger logger = Logger.getLogger(PersonServices.class.getName());

    @Autowired
    PersonRepository repository;

    public List findAll() {

        logger.info("Finding all person!!");
        return repository.findAll();
    }
}

Indica as regras do negócio.

7. Exemplo de Controller

@RestController
@RequestMapping("/clientes")
public class ClienteController {
   @GetMapping
   public String listar() {
       return "Lista de clientes";
   }
}

Recebe as requisições HTTP(GET, POST, PUT, DELETE). Em uma API real, o Controller normalmente delega a operação para um Service.

8. Exemplo de Repository


public interface PersonRepository extends JpaRepository {
    Optional findByEmail(String email);

}

Responsável pelo acesso ao banco de dados, realiza operações como buscar, criar, atualizar e deletar.

9. O que é CRUD?

  • Create: criar registros.
  • Read: consultar registros.
  • Update: atualizar registros.
  • Delete: excluir registros.

Essas operações são frequentemente associadas aos métodos HTTP POST, GET, PUT ou PATCH, e DELETE.

10. JPA e Hibernate

JPA é uma especificação para persistência de objetos Java. Hibernate é uma implementação popular dessa especificação.

@Entity
public class Cliente {
   @Id
   @GeneratedValue(strategy = GenerationType.IDENTITY)
   private Long id;
   private String nome;
}

Uma entidade normalmente representa dados que podem ser armazenados em uma tabela do banco.
