🗄️ PostgreSQL

Consultas e gerenciamento de dados.

1. O que é PostgreSQL?

É um sistema gerenciador de banco de dados relacional que utiliza SQL para consultar e manipular dados.

2. Comandos básicos

-- Consultar dados
SELECT * FROM clientes;
-- Inserir dados
INSERT INTO clientes (nome)
VALUES ('Amanda');
-- Atualizar dados
UPDATE clientes
SET nome = 'Ana'
WHERE id = 1;
-- Excluir dados
DELETE FROM clientes
WHERE id = 1;

O WHERE limita quais registros serão atualizados ou excluídos.

3. Filtrar e ordenar

SELECT *
FROM clientes
WHERE idade >= 18
ORDER BY nome ASC;
  • WHERE: filtra registros.
  • ORDER BY: ordena resultados.
  • GROUP BY: agrupa registros.
  • HAVING: filtra grupos.

4. JOINs

JOIN combina dados relacionados de duas ou mais tabelas.

SELECT clientes.nome, pedidos.id
FROM clientes
INNER JOIN pedidos
   ON clientes.id = pedidos.cliente_id;
  • INNER JOIN: somente correspondências.
  • LEFT JOIN: todos da tabela à esquerda e as correspondências da direita.
  • RIGHT JOIN: todos da tabela à direita e as correspondências da esquerda.
  • FULL JOIN: todas as linhas das duas tabelas, com correspondências quando existirem.

5. Chaves e restrições

  • PRIMARY KEY: identifica cada registro.
  • FOREIGN KEY: relaciona tabelas.
  • UNIQUE: impede valores duplicados na restrição.
  • NOT NULL: impede valores nulos.
  • CHECK: valida uma condição.
  • DEFAULT: define um valor padrão.

6. Índices e transações

Índices podem acelerar consultas, mas consomem espaço e adicionam custo às alterações de dados.

CREATE INDEX idx_cliente_nome
ON clientes (nome);
BEGIN;
UPDATE contas
SET saldo = saldo - 100
WHERE id = 1;
COMMIT;

COMMIT confirma a transação. ROLLBACK desfaz as alterações ainda não confirmadas.
